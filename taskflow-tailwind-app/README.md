# TaskFlow — Tailwind CSS

A project/task management CRUD app built with React, Vite and Tailwind CSS.

Features:
- Create, edit and delete tasks
- Search tasks
- Filter by status and priority
- Task details modal
- Responsive UI
- Component-based React architecture and props

Run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

Tailwind is configured with the Vite plugin.
