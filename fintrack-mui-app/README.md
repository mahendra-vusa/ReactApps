# FinTrack — Material UI

A different CRUD application: an expense manager built with React, Vite and Material UI.

Features:
- Create, edit and delete expenses
- Search and category filtering
- Expense details dialog
- Spending summary cards
- Material UI tables, dialogs, forms, chips and icons
- Component-based React architecture and props

Run:

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
